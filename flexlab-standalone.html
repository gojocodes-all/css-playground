MENTAL MODEL

Property map

01

Choose the main axis

flex-direction decides whether the main flow is a row or column, including reversed versions.

02

Decide whether lines may wrap

flex-wrap creates additional flex lines when items no longer fit.

03

Distribute space

justify-content works on the main axis. align-items works inside each line on the cross axis.

04

Arrange multiple lines

align-content moves or spreads the flex lines themselves, so it needs multiple lines and spare cross-axis space.

05

Resolve item sizes

flex-basis proposes a starting main size. Positive space uses grow factors; negative space uses scaled shrink factors.

06

Override individuals

order, align-self, auto margins, and the flex shorthand control one item at a time.

Accessibility warning: CSS order changes visual order, not keyboard or screen-reader order. Use it carefully.
